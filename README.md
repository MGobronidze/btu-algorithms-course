თითოეული ლექცია — ცალკეული, დამოუკიდებელი `.html` ფაილია: build-ის, `npm install`-ის ან სერვერის გარეშე, უბრალოდ ორმაგი დაწკაპუნებით იხსნება ბრაუზერში. თითოეული გვერდი შეიცავს:

- ღრმა თეორიულ მასალას (განახლებული და შესწორებული ორიგინალი ლექციის კონსპექტის მიხედვით)
- Python 3.12+ ოპტიმიზებულ, კომენტირებულ კოდის მაგალითებს
- Big-O დროითი/მეხსიერების სირთულის ანალიზს
- ინტერაქტიულ ვიზუალიზაციებს (call stack, ალგორითმის მუშაობის სიმულაცია და ა.შ.)
- Tech Industry Insights — რეალურ მაგალითებს დიდი კომპანიების პრაქტიკიდან
- ინტერაქტიულ სავარჯიშოებს ამოხსნებით (საბაზისო + LeetCode-ტიპის Easy/Medium/Hard)

## ლოკალურად გაშვება

უბრალოდ გახსენით `index.html` ბრაუზერში. თუ გსურთ ლოკალური სერვერით გაშვება (რეკომენდებულია რელატიური ბმულების გამო):

```bash
python3 -m http.server 8000
# შემდეგ გახსენით: http://localhost:8000
```

## GitHub Pages-ზე გამოქვეყნება

1. შექმენით ახალი repository და ატვირთეთ ამ საქაღალდის სრული შემცველობა.
2. GitHub-ზე: **Settings → Pages → Source** — აირჩიეთ `main` ბრენჩი და `/ (root)` საქაღალდე.
3. რამდენიმე წუთში საიტი ხელმისაწვდომი იქნება მისამართზე:
   `https://<თქვენი-username>.github.io/<repo-სახელი>/`

დამატებითი კონფიგურაცია არ სჭირდება — არც build step, არც dependency ინსტალაცია.
