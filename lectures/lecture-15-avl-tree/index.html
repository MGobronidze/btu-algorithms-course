AVL ხე

თვითბალანსირებადი ორობითი ძიების ხე: როგორ ინარჩუნებს ის სიმაღლეს O(log n)-ზე ყოველი ჩასმის შემდეგ.

ბალანსის ფაქტორიროტაციაLL · LR · RR · RLAVL sort

რა არის AVL ხე და რატომ გვჭირდება

AVL ხე (ადელსონ-ველსკი და ლანდისი, 1962) არის BST, სადაც ყოველი კვანძისთვის მარცხენა და მარჯვენა ქვეხის სიმაღლეთა სხვაობა არ აღემატება ერთს. ამ სხვაობას კვანძის ბალანსის ფაქტორი ეწოდება:

BF(v) = h(v.left) − h(v.right) ∈ {−1, 0, +1}

პრობლემა, რასაც ეს წყვეტს: ჩვეულებრივ BST-ში დალაგებული მიმდევრობის ჩასმა ხეს სიას აქცევს და ოპერაციები O(n) ხდება. ჩვენ გაზომილ ექსპერიმენტში 1…3000 დალაგებული გასაღების BST-ში ჩასმა Python-ის რეკურსიის ლიმიტს (1000) არღვევს, ხოლო AVL-ში 100 000 დალაგებული გასაღები სიმაღლე 17-ს იძლევა.

სიმაღლე

ცარიელი ხე (None) = 0, ფოთოლი = 1.

BF > 1

მარცხნივ გადახრილი: შემთხვევა LL ან LR.

BF < −1

მარჯვნივ გადახრილი: შემთხვევა RR ან RL.

🔍 შესწორება 1 — ბალანსის ნიშანი

პრეზენტაციაში სლაიდი 25 განსაზღვრავს BF = მარცხენა − მარჯვენა, მაგრამ სლაიდების 21–24 დიაგრამებზე მარცხნივ გადახრილ კვანძს აწერია −2 (ანუ მარჯვენა − მარცხენა). ერთი ნიშნის შეცდომა LL/RR-ის აღრევას იწვევს. ჩვენ ყველგან ვიყენებთ მარცხენა − მარჯვენა: LL-ს შეესაბამება +2, RR-ს −2.

🔍 შესწორება 2 — სიმაღლის კონვენცია

სლაიდებზე height() და Node არ არის ნაჩვენები. თუ ფოთლის სიმაღლეს 0 დავაყენებთ, ხოლო height(None)-ს 0 დავტოვებთ, ფოთოლი და ცარიელი ქვეხე არ განირჩევა. გავუშვით: 1, 2, 3 მიმდევრობის ჩასმა უკვე რეალურად დისბალანსირებულ ხეს გვიბრუნებს. წესი: ფოთოლი = 1, None = 0.

როტაციები და ოთხი დისბალანსი

ბალანსის აღსადგენად საკმარისია ორი პრიმიტივი — rotate_left და rotate_right. სლაიდის „ოთხი როტაცია“ სინამდვილეში ამ ორის კომბინაციებია: LL და RR ერთი პრიმიტივია, LR და RL — ორი. ორივე O(1)-ია და ინარჩუნებს in-order მიმდევრობას, ამიტომ BST თვისება არ ირღვევა. T1…T4 არის ნებისმიერი ქვეხე.

"""AVL tree — clean version of lecture 15 (insertion + AVL sort)."""
from __future__ import annotations

from collections.abc import Iterable, Iterator
from typing import Protocol


class Comparable(Protocol):
    def __lt__(self, other, /) -> bool: ...


class Node[K: Comparable]:
    """One AVL node. A leaf has height 1, a missing child (None) has height 0."""

    __slots__ = ("key", "left", "right", "height", "count")

    def __init__(self, key: K) -> None:
        self.key = key
        self.left: Node[K] | None = None
        self.right: Node[K] | None = None
        self.height = 1
        self.count = 1  # multiplicity of the key (used by avl_sort)


def height[K: Comparable](node: Node[K] | None) -> int:
    return node.height if node is not None else 0


def balance_factor[K: Comparable](node: Node[K] | None) -> int:
    """height(left) - height(right); a valid AVL node has -1, 0 or +1."""
    return height(node.left) - height(node.right) if node is not None else 0


def update_height[K: Comparable](node: Node[K]) -> None:
    node.height = 1 + max(height(node.left), height(node.right))


def rotate_right[K: Comparable](z: Node[K]) -> Node[K]:
    """Right rotation around z (left-heavy). Returns the new subtree root."""
    y = z.left
    assert y is not None, "rotate_right needs a left child"
    z.left, y.right = y.right, z
    update_height(z)  # z is now the lower node -> update it first
    update_height(y)
    return y


def rotate_left[K: Comparable](z: Node[K]) -> Node[K]:
    """Left rotation around z (right-heavy). Returns the new subtree root."""
    y = z.right
    assert y is not None, "rotate_left needs a right child"
    z.right, y.left = y.left, z
    update_height(z)
    update_height(y)
    return y


def rebalance[K: Comparable](z: Node[K]) -> Node[K]:
    """Restore the AVL property at z (children already valid AVL trees)."""
    update_height(z)
    bf = balance_factor(z)
    if bf > 1:  # left-heavy: LL or LR
        assert z.left is not None
        if balance_factor(z.left) < 0:  # LR -> first rotate the child left
            z.left = rotate_left(z.left)
        return rotate_right(z)
    if bf < -1:  # right-heavy: RR or RL
        assert z.right is not None
        if balance_factor(z.right) > 0:  # RL -> first rotate the child right
            z.right = rotate_right(z.right)
        return rotate_left(z)
    return z


def insert[K: Comparable](node: Node[K] | None, key: K) -> Node[K]:
    """Insert key, return the (possibly new) root. Duplicates raise count."""
    if node is None:
        return Node(key)
    if key < node.key:
        node.left = insert(node.left, key)
    elif node.key < key:
        node.right = insert(node.right, key)
    else:
        node.count += 1
        return node
    return rebalance(node)


def inorder[K: Comparable](node: Node[K] | None) -> Iterator[K]:
    """In-order traversal; a key with count c is yielded c times."""
    if node is not None:
        yield from inorder(node.left)
        yield from (node.key for _ in range(node.count))
        yield from inorder(node.right)


def avl_sort[K: Comparable](items: Iterable[K]) -> list[K]:
    """O(n log n) sort: n balanced insertions, then one in-order pass."""
    root: Node[K] | None = None
    for item in items:
        root = insert(root, item)
    return list(inorder(root))

🎯 დალაგება AVL ხით

avl_sort არის n ჩასმა (თითო O(log n)) და ერთი in-order გავლა O(n), ანუ ჯამში O(n log n) დროში და O(n) მეხსიერებაში, უარეს შემთხვევაშიც. გაფრთხილება: BST-ზე დაფუძნებული დალაგება უარეს შემთხვევაში O(n²) იყო.

სირთულის ანალიზი

🎯 შედარება სხვა დალაგებებთან და კავშირი ლექცია 16-თან

Heap Sort (ლექცია 12) იგივე O(n log n)-ია, მაგრამ დამატებით მეხსიერებას არ ითხოვს (O(1)), ხოლო AVL sort-ს O(n) სჭირდება. სამაგიეროდ AVL ხე დალაგებულია ყოველ მომენტში: ახალი ელემენტი O(log n)-ში ჩაჯდება და ძიება, min/max ან in-order მაშინვე ხელმისაწვდომია. AVL sort, Merge და Quick Sort ერთი ოჯახია (ელემენტებს ერთმანეთს ადარებს), ამიტომ შედარებაზე დაფუძნებული დალაგება Ω(n log n)-ზე სწრაფი ვერ იქნება. შემდეგ ლექციაზე Counting და Radix Sort ამ ზღვარს შედარების გარეშე გადალახავს.

Balanced Binary Tree (LC 110) Easy

დაადგინეთ, აქვს თუ არა ხეს AVL-ის სიმაღლის თვისება (ეს არის სლაიდების 5 და 7 ხეების შემოწმება კოდით). იდეა: ერთ გავლაში ვაბრუნებთ სიმაღლეს, დისბალანსისას კი −1-ს. დრო O(n), მეხსიერება O(h).

lc110.py
@dataclass
class TreeNode:
    val: int = 0
    left: 'TreeNode | None' = None
    right: 'TreeNode | None' = None


def is_balanced(root: TreeNode | None) -> bool:
    """One pass: return -1 as 'unbalanced' sentinel, else the height. O(n)/O(h)."""
    def h(n: TreeNode | None) -> int:
        if n is None:
            return 0
        lh = h(n.left)
        if lh == -1:
            return -1
        rh = h(n.right)
        if rh == -1 or abs(lh - rh) > 1:
            return -1
        return 1 + max(lh, rh)
    return h(root) != -1
My Calendar I (LC 729) Medium

ყოველი book(start, end) ჯავშნის ინტერვალს [start, end), თუ ის არცერთს არ კვეთს. იდეა: AVL ხეში ვინახავთ საწყისებს და ვეძებთ უახლოეს წინა და მომდევნო ჯავშანს. დრო O(log n) ჯავშანზე. გამოცდილია brute-force-თან 3000 შემთხვევით სცენარზე და 10 000 ჯავშანზე ხის სიმაღლე 14-ია.

lc729.py
from avl import Node, insert  # ლექციის კოდი


class MyCalendar:
    """LC 729: half-open intervals [start, end); AVL keyed by start."""
    def __init__(self) -> None:
        self.root: Node[int] | None = None
        self.end_of: dict[int, int] = {}

    def _neighbours(self, start: int) -> tuple[int | None, int | None]:
        prev = nxt = None
        node = self.root
        while node is not None:
            if node.key <= start:      # candidate for "largest start <= start"
                prev = node.key
                node = node.right
            else:                      # candidate for "smallest start > start"
                nxt = node.key
                node = node.left
        return prev, nxt

    def book(self, start: int, end: int) -> bool:
        prev, nxt = self._neighbours(start)
        if prev is not None and self.end_of[prev] > start:
            return False
        if nxt is not None and nxt < end:
            return False
        self.root = insert(self.root, start)
        self.end_of[start] = end
        return True
Count of Smaller Numbers After Self (LC 315) Hard

თითოეული nums[i]-სთვის იპოვეთ მასზე მარჯვნივ მდგომი, მასზე მცირე ელემენტების რაოდენობა. იდეა: მასივს მარჯვნიდან მარცხნივ გავუყვეთ, AVL კვანძში დავამატოთ size (ქვეხის ელემენტების რაოდენობა) და cnt (დუბლიკატები); მცირე ელემენტების დათვლა O(log n)-ია, ჯამში O(n log n). ემთხვევა brute-force-ს 1500 შემთხვევით მასივზე, 10⁵ ელემენტს დაახლოებით 1 წამში ამუშავებს.

lc315.py
class _N:
    __slots__ = ("key", "left", "right", "height", "cnt", "size")
    def __init__(self, key: int) -> None:
        self.key = key; self.left = self.right = None
        self.height = 1; self.cnt = 1; self.size = 1   # size = keys in subtree incl. duplicates

def _h(n: _N | None) -> int: return n.height if n else 0
def _s(n: _N | None) -> int: return n.size if n else 0

def _upd(n: _N) -> None:
    n.height = 1 + max(_h(n.left), _h(n.right))
    n.size = n.cnt + _s(n.left) + _s(n.right)

def _rot_r(z: _N) -> _N:
    y = z.left; z.left, y.right = y.right, z; _upd(z); _upd(y); return y

def _rot_l(z: _N) -> _N:
    y = z.right; z.right, y.left = y.left, z; _upd(z); _upd(y); return y

def _rebalance(z: _N) -> _N:
    _upd(z)
    bf = _h(z.left) - _h(z.right)
    if bf > 1:
        if _h(z.left.left) < _h(z.left.right): z.left = _rot_l(z.left)
        return _rot_r(z)
    if bf < -1:
        if _h(z.right.right) < _h(z.right.left): z.right = _rot_r(z.right)
        return _rot_l(z)
    return z

def _insert(n: _N | None, key: int) -> _N:
    if n is None: return _N(key)
    if key < n.key: n.left = _insert(n.left, key)
    elif key > n.key: n.right = _insert(n.right, key)
    else: n.cnt += 1
    return _rebalance(n)

def _count_less(n: _N | None, key: int) -> int:
    total = 0
    while n is not None:
        if key <= n.key: n = n.left
        else:
            total += _s(n.left) + n.cnt
            n = n.right
    return total

def count_smaller(nums: list[int]) -> list[int]:
    """counts[i] = #{j > i : nums[j] < nums[i]}. Right-to-left + order-statistic AVL. O(n log n)."""
    root: _N | None = None
    out = [0] * len(nums)
    for i in range(len(nums) - 1, -1, -1):
        out[i] = _count_less(root, nums[i])
        root = _insert(root, nums[i])
    return out
