ბმული სია

პირველი მონაცემთა სტრუქტურა კურსში, სადაც ელემენტები მეხსიერებაში ერთმანეთის გვერდით აღარ დევს — ისინი მხოლოდ „მიმართულებებით" არიან დაკავშირებული.

01 — ახალი კატეგორია

რა არის ბმული სია

აქამდე ნასწავლი ყველა სტრუქტურა — Python-ის list — მეხსიერებაში ინახავს ელემენტებს თანმიმდევრულად, ერთმანეთის გვერდით. ბმული სია სრულიად განსხვავებულ პრინციპზეა აგებული: თითოეული ელემენტი („კვანძი", node) ინახავს (1) საკუთარ მონაცემს და (2) შემდეგი კვანძის მისამართს — ისინი შეიძლება მეხსიერების სრულიად სხვადასხვა ადგილას იყვნენ განთავსებული.

ბოლო კვანძის „შემდეგი" მისამართი — None (Python-ში) ან NULL — სიის დასასრულს აღნიშნავს. სიაზე წვდომა ხდება მხოლოდ ერთი წერტილიდან — head-იდან (პირველი კვანძი) — და ყოველი შემდეგი კვანძი მიიღწევა მხოლოდ წინა კვანძის next-ის მეშვეობით.

💡

ძირითადი კომპრომისი: მასივი გვაძლევს O(1) წვდომას ინდექსით, მაგრამ ჩასმა/წაშლა შუაში მოითხოვს ყველა შემდგომი ელემენტის „წევას" — O(n). ბმული სია პირიქითაა: წვდომა კონკრეტულ პოზიციაზე O(n)-ია (თანმიმდევრული გავლა აუცილებელია), მაგრამ ჩასმა/წაშლა, როცა ადგილი უკვე ვიცით, O(1)-ია — უბრალოდ რამდენიმე მისამართის გადანაცვლება, დანარჩენი მონაცემის შეხების გარეშე.

02 — ვარიაციები

ბმული სიების ტიპები

ერთმხრივი (Singly)

თითოეული კვანძი მიუთითებს მხოლოდ შემდეგ ელემენტზე. ყველაზე მარტივი და ამ ლექციის მთავარი ფოკუსი.

ორმხრივი (Doubly)

თითოეული კვანძი მიუთითებს როგორც შემდეგზე, ისე წინა ელემენტზეც — შესაძლებელს ხდის უკუმიმართულებითაც გავლას, დამატებითი მეხსიერების ხარჯზე.

წრიული (Circular)

ბოლო კვანძი None-ის ნაცვლად პირველ კვანძზე მიუთითებს — ქმნის მარყუჟს. გამოსადეგია „მორიგეობის" ამოცანებში (round-robin).

03 — სამშენებლო ბლოკი

კვანძის სტრუქტურა

ბმული სია იწყება ერთი მარტივი კლასით — Node. ყველაფერი დანარჩენი ამ ერთ იდეაზეა აგებული.

node.py
class Node:
    """ერთმხრივი ბმული სიის ერთი კვანძი."""
    def __init__(self, data):
        self.data = data   # ნებისმიერი სახის ინფორმაცია
        self.next = None   # შემდეგი კვანძის მისამართი (თავდაპირველად — არცერთი)

თავად „სია" ცალკე კლასის სახით არც კი არის აუცილებელი — საკმარისია ერთი ცვლადი, რომელიც head კვანძზე მიუთითებს. მთელი დანარჩენი სია ამ ერთი მისამართიდან „მიიღწევა" next-ების ჯაჭვის გავლით.

04 — საბაზისო ოპერაციები

გავლა, ძებნა, სიგრძე

სამივე ოპერაცია ერთსა და იმავე პატერნს იმეორებს — დავიწყოთ head-იდან, ვიაროთ next-ებით None-მდე:

traverse.py
def traverse_linked_list(head: "Node") -> None:
    current = head
    while current is not None:
        print(current.data, end=' ')   # ერთ ხაზზე, სივრცით გამოყოფილი
        current = current.next
    print()
🔍

შესწორება ორიგინალ მასალასთან შედარებით: საწყისი კოდი წერდა print(current.data), — მიბაძვით Python 2-ის სინტაქსზე, სადაც ბოლო მძიმე ბეჭდვისას ახალ ხაზზე გადასვლას თრგუნავდა. Python 3-ში ეს აღარ მუშაობს ასე — მძიმე უბრალოდ ქმნის ერთელემენტიან tuple-ს print()-ის შედეგისგან და არავითარ გავლენას არ ახდენს გამოტანაზე. შედეგად, კომენტარის დაპირების („სივრცით გამოყოფილი") საწინააღმდეგოდ, თითოეული მნიშვნელობა ცალკე ხაზზე დაიბეჭდებოდა. სწორი Python 3 იდიომაა print(x, end=' ').

ძებნა
def search_linked_list(head: "Node", target) -> bool:
    current = head
    while current is not None:
        if current.data == target:
            return True
        current = current.next
    return False
სიგრძე
def find_length(head: "Node") -> int:
    length = 0
    current = head
    while current is not None:
        length += 1
        current = current.next
    return length

სამივე ოპერაცია: O(n) დროში, O(1) დამატებით მეხსიერებაში — მასივისგან განსხვავებით, აქ არ არსებობს len()-ის მსგავსი მუდმივი დროის შემოწმება, რადგან სიგრძე არსად ცენტრალურად არ ინახება.

05 — სცადეთ თავად

ინტერაქტიული ბმული სია

ააგეთ სია, ჩასვით და წაშალეთ კვანძები — ზუსტად იმ ოპერაციებით, რომლებსაც ქვემოთ კოდშიც ვხედავთ.

გაითვალისწინეთ — ჩასმა/წაშლა თავში ყოველთვის ერთი ნაბიჯია, მიუხედავად სიის სიგრძისა (O(1)); ბოლოში ან შუაში კი მოითხოვს იქამდე „მისვლას" (O(n)).

06 — ჩასმის ოპერაციები

ჩასმა — სამი ვარიანტი

ჩასმა თავში — O(1)

def insert_at_beginning(head: "Node", value) -> "Node":
    new_node = Node(value)
    new_node.next = head    # ახალი კვანძი მიუთითებს ძველ head-ზე
    head = new_node         # head ახლა ახალ კვანძზე მიუთითებს
    return head

ჩასმა ბოლოში — O(n)

def insert_at_end(head: "Node", value) -> "Node":
    new_node = Node(value)
    if head is None:
        return new_node
    current = head
    while current.next is not None:   # ბოლო კვანძამდე „მისვლა"
        current = current.next
    current.next = new_node
    return head

ჩასმა კონკრეტულ პოზიციაზე — O(n)

def insert_at_position(head: "Node", pos: int, data) -> "Node":
    if pos < 1:
        return head
    if pos == 1:
        new_node = Node(data)
        new_node.next = head
        return new_node

    prev = head
    count = 1
    while count < pos - 1 and prev is not None:
        prev = prev.next
        count += 1
    if prev is None:          # პოზიცია სიის სიგრძეს აღემატება
        return head

    new_node = Node(data)
    new_node.next = prev.next
    prev.next = new_node
    return head

თანმიმდევრობას მნიშვნელობა აქვს: ჯერ new_node.next = prev.next, მერე prev.next = new_node — თუ ეს ორი ხაზი გადავანაცვლოთ, prev.next-ის ძველი მნიშვნელობა დაიკარგება, სანამ ახალ კვანძს მივაბამდეთ, და დარჩენილი სია „მოწყდება".

07 — წაშლის ოპერაციები

წაშლა — სამი ვარიანტი

წაშლა თავიდან — O(1)

def remove_first_node(head: "Node") -> "Node":
    if not head:
        return None
    head = head.next   # head უბრალოდ "გადახტება" შემდეგ კვანძზე
    return head

წაშლა ბოლოდან — O(n)

def remove_last_node(head: "Node") -> "Node":
    if head is None:
        return None
    if head.next is None:          # ერთადერთი ელემენტი
        return None

    second_last = head
    while second_last.next.next is not None:
        second_last = second_last.next
    second_last.next = None        # "მოვწყვიტოთ" ბოლო კვანძი
    return head
⚠️

ერთმხრივი სიის შეზღუდვა: ბოლოდან წაშლას სჭირდება ბოლოს წინა კვანძის პოვნა — მაგრამ next მხოლოდ წინ მიუთითებს, უკან დაბრუნების გზა არ არსებობს, ამიტომ თავიდანვე გვიწევს მთელი სიის გავლა. ორმხრივ სიაში (prev მაჩვენებლით) ეს ოპერაცია O(1)-ში შესრულდებოდა — ერთ-ერთი მთავარი მიზეზი, რატომაც არსებობს ორმხრივი ვარიანტი.

წაშლა კონკრეტული პოზიციიდან — O(n)

def delete_at_position(head: "Node", position: int) -> "Node":
    if head is None or position < 1:
        return head
    if position == 1:
        return head.next

    current = head
    for _ in range(position - 2):
        if current is not None:
            current = current.next
    if current is None or current.next is None:
        return head             # პოზიცია დიაპაზონს გარეთაა

    current.next = current.next.next   # "გვერდი ავუაროთ" წასაშლელ კვანძს
    return head
08 — არჩევანი

მასივი vs ბმული სია

ოპერაციამასივი (Python list)ბმული სია
წვდომა ინდექსითO(1)O(n)
ჩასმა/წაშლა თავშიO(n)O(1)
ჩასმა/წაშლა ბოლოშიO(1) ამორტიზებულიO(n) (O(1) ორმხრივში, tail-მაჩვენებლით)
ძებნა მნიშვნელობითO(n)O(n)
მეხსიერების განლაგებათანმიმდევრული — cache-მეგობრულიმიმოფანტული — დამატებითი მეხსიერება next-ისთვის
ზომის ცვლილებასაჭიროებს ხელახალ გამოყოფას დიდი ზრდისასბუნებრივად დინამიური
🎯

როდის აირჩიოთ ბმული სია: როცა ელემენტთა რაოდენობა ხშირად იცვლება და ჩასმა/წაშლა ხდება ცნობილ პოზიციაზე (განსაკუთრებით თავში) — მაშინ ბმული სია მასივს აჯობებს. თუ ძირითადად ინდექსით წვდომა გჭირდებათ, მასივი (ან Python-ის list) თითქმის ყოველთვის სჯობს.

🧠

LRU Cache

ერთ-ერთი ყველაზე ცნობილი გასაუბრების ამოცანა (LeetCode 146) აგებულია ორმხრივ ბმულ სიაზე + hash map-ზე — სია ინარჩუნებს გამოყენების რიგითობას, ხოლო hash map აძლევს O(1) წვდომას კონკრეტულ კვანძზე.

🖥️

ოპერაციული სისტემები

თავისუფალი მეხსიერების მონაკვეთების მართვა (free list) ხშირად ბმული სიით ხდება — მეხსიერების გამოყოფა/გათავისუფლება დინამიურია, ზუსტად ისე, როგორც ბმული სია იზრდება და იკლებს.

⛓️

Blockchain

თითოეული ბლოკი შეიცავს წინა ბლოკის hash-ს — კონცეპტუალურად ეს არის ბმული სია (ან უფრო ზუსტად, ერთმხრივი, უკუმიმართებით), სადაც „მისამართის" ნაცვლად კრიპტოგრაფიული hash გამოიყენება.

10 — პრაქტიკა

სავარჯიშოები

დღეს ნასწავლი ოპერაციები (გავლა, ძებნა) წარმოადგენს საფუძველს სამივე ქვემოთ მოცემული ამოცანისთვის — განსაკუთრებით „swift/slow" ორმაჩვენებლიანი ტექნიკა, რომელსაც მომდევნო ლექციაშიც შევხვდებით (ციკლის აღმოჩენისას).

Middle of the Linked List მარტივი

იპოვეთ სიის შუა კვანძი ერთი გავლით — სიგრძის წინასწარი გამოთვლის გარეშე (LeetCode 876).

def middle_node(head: "Node") -> "Node":
    slow = fast = head
    while fast is not None and fast.next is not None:
        slow = slow.next        # ერთი ნაბიჯით
        fast = fast.next.next   # ორი ნაბიჯით
    return slow

იდეა — „swift/slow" (კურდღელი და კუ): ორი მაჩვენებელი მოძრაობს სხვადასხვა სიჩქარით. როცა სწრაფი ბოლოს მიაღწევს, ნელი ზუსტად შუაშია — რადგან ნელმა გაიარა ზუსტად ნახევარი მანძილი, რაც სწრაფმა. სირთულე: O(n) დროში, O(1) სივრცეში — ერთი გავლა, ორი გავლის ნაცვლად (პირველი — სიგრძის დასათვლელად, მეორე — შუამდე მისასვლელად).

Remove Nth Node From End of List საშუალო

წაშალეთ ბოლოდან n-ური კვანძი, ერთი გავლით (LeetCode 19) — მაშინაც კი, თუ სიის სიგრძე წინასწარ უცნობია.

def remove_nth_from_end(head: "Node", n: int) -> "Node":
    dummy = Node(0)
    dummy.next = head
    fast = slow = dummy

    for _ in range(n):       # fast-ს n ნაბიჯით ვასწრებთ
        fast = fast.next

    while fast.next is not None:
        fast = fast.next
        slow = slow.next

    slow.next = slow.next.next   # slow ახლა წასაშლელის წინაა
    return dummy.next

„დამხმარე" (dummy) კვანძის ტრიუკი: თუ წასაშლელი ზუსტად head-ია, სპეციალური შემთხვევის აღწერა (if-ით) აღარ გვჭირდება — dummy ყოველთვის იძლევა „კვანძს head-მდე", რაც კოდს ამარტივებს. ეს ძალიან გავრცელებული პატერნია ბმული სიის ამოცანებში.

Intersection of Two Linked Lists რთული

ორი ბმული სია შეიძლება ერთხელაც კი „ერწყმოდეს" და საერთო კუდი ჰქონდეს. იპოვეთ ის კვანძი, საიდანაც იწყება ეს გაერთიანება — O(1) დამატებითი მეხსიერებით (LeetCode 160).

def get_intersection_node(headA: "Node", headB: "Node") -> "Node":
    a, b = headA, headB
    while a is not b:
        a = a.next if a is not None else headB
        b = b.next if b is not None else headA
    return a   # ან None, თუ საერთო წერტილი არ არსებობს

ელეგანტური ხრიკი: როცა მაჩვენებელი მიაღწევს საკუთარი სიის ბოლოს, „გადახტება" მეორე სიის თავზე. თუ ორივე მაჩვენებელი ერთად გაივლის len(A) + len(B) კვანძს, ისინი აუცილებლად შეხვდებიან — ან გადაკვეთის წერტილში, ან ორივე None-ზე ერთდროულად (თუ გადაკვეთა არ არსებობს). ეს გვერდს უვლის სიგრძეების წინასწარ გამოთვლას და დამატებით set-საც კი არ საჭიროებს.
