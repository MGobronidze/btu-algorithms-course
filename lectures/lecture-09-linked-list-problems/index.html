01 — გაგრძელება

ლექცია 7-დან აქამდე

შუალედური გამოცდის შემდეგ ვუბრუნდებით ბმულ სიას — ახლა კი აღარ ვაშენებთ საბაზისო ოპერაციებს, არამედ ვხსნით ოთხ კლასიკურ, გასაუბრებებზე ხშირად შემხვედრ ამოცანას, რომლებიც ყველა ამ საბაზისო ოპერაციებზეა აგებული.

🔗

საერთო ძაფი: ოთხივე დღევანდელი ამოცანა ამოიხსნება ერთი-ორი მაჩვენებლით (curr, prev, slow/fast) და მასივის ან დამატებითი მეხსიერების გარეშე. სწორედ ეს არის ბმული სიების ამოცანების საერთო ხასიათი — ცოტა მეხსიერებით, ბევრი „მაჩვენებლების ჟონგლირებით".

02 — ამოცანა 1

Linked List Cycle

ამოცანა: დაადგინეთ, შეიცავს თუ არა ბმული სია ციკლს (მარყუჟს) — ანუ უბრუნდება თუ არა რომელიმე კვანძის next ადრე უკვე მონახულებულ კვანძს.

მიდგომა 1 — HashSet

def detect_loop(head: "Node") -> bool:
    visited = set()
    while head is not None:
        if head in visited:      # კვანძს უკვე ვნახეთ → ციკლია
            return True
        visited.add(head)
        head = head.next
    return False   # head-მა None-ს მიაღწია → ციკლი არაა

მიდგომა 2 — Floyd-ის „კუისა და კურდღლის" ალგორითმი

def detect_loop(head: "Node") -> bool:
    slow = fast = head
    while slow and fast and fast.next:
        slow = slow.next        # ერთი ნაბიჯი
        fast = fast.next.next   # ორი ნაბიჯი
        if slow is fast:        # შეხვდნენ → ციკლია
            return True
    return False
🐢

რატომ ბადებს კურდღელი კუს, თუ ციკლია: თუ ციკლი არსებობს, ორივე მაჩვენებელი მასში „ჩაიხვევა" და ვერასდროს გავა — ეს გარანტირებთ, რომ საბოლოოდ შეხვდებიან (fast აგდებს slow-ს, სანამ არ დაეწევა ციკლის შიგნით). თუ ციკლი არ არსებობს, fast უბრალოდ პირველი მიაღწევს None-ს.

მიდგომადროითი სირთულესივრცითი სირთულე
HashSetO(n)O(n)
Floyd (slow/fast)O(n)O(1)
🔍

სტილისტური დაკვირვება: ორიგინალ კოდში წერია if slow == fast. Node-ის კლასს საკუთარი __eq__ არ აქვს განსაზღვრული, ამიტომ Python ავტომატურად უბრუნდება ობიექტის იდენტობის შედარებას — ანუ == აქ ფაქტობრივად იგივეა, რაც is. მაინც, როცა განზრახვა „იგივე ობიექტია თუ არა" შემოწმებაა (და არა მნიშვნელობითი ტოლობა), იდიომატური და მკაფიო Python მოითხოვს is-ს — ეს განზრახვას ცალსახად აცხადებს და მომავალში, თუ ვინმემ Node-ს __eq__ დაამატებს, ბაგისგან იცავს კოდს.

03 — ამოცანა 2

Remove Duplicates from Sorted List

ამოცანა: მოცემულია დალაგებული ბმული სია — წაშალეთ ყველა დუბლიკატი ისე, რომ თითოეული მნიშვნელობა მხოლოდ ერთხელ დარჩეს.

ოპტიმალური მიდგომა — ორი მეზობელი კვანძის შედარება (O(1) სივრცე)

რადგან სია უკვე დალაგებულია, ყველა დუბლიკატი ერთმანეთის გვერდიგვერდ დგას — საკმარისია მხოლოდ მეზობელი წყვილების შედარება, HashSet საერთოდ არ გვჭირდება:

def remove_duplicates(head: "Node") -> "Node":
    curr = head
    while curr and curr.next:
        if curr.data == curr.next.data:
            curr.next = curr.next.next   # გამოვტოვოთ დუბლიკატი
        else:
            curr = curr.next
    return head
💡

რატომ არა curr = curr.next ყოველთვის: დუბლიკატის პოვნისას curr ადგილზე რჩება განზრახ — შესაძლოა სამი ან მეტი ზედიზედ ტოლი მნიშვნელობა იყოს ([1,1,1,2]), და curr-ს სჭირდება იგივე პოზიციაზე დარჩენა, სანამ ყველა დუბლიკატს არ „გადაახტება".

ალტერნატივები

მიდგომამოქმედების არეალისირთულე
ორი მეზობელი კვანძი (ზემოთ)მხოლოდ დალაგებული სიაO(n) დრო, O(1) სივრცე
HashSet ყველა მონახულებულზენებისმიერი სია (დაულაგებელიც!)O(n) დრო, O(n) სივრცე
რეკურსიული (იგივე ორი-კვანძის იდეა)დალაგებული სიაO(n) დრო, O(n) სივრცე — call stack

კარგი მაგალითია იმისა, თუ როგორ იძლევა ამოცანის დამატებითი პირობა (აქ: „დალაგებულია") გზას ბევრად უფრო მარტივი და მეხსიერება-ეფექტური ამონახსნისკენ — ზუსტად ისე, როგორც ლექცია 6-ში Search a 2D Matrix-ის ორ ვერსიას შორის ვნახეთ.

04 — ამოცანა 3

Merge Two Sorted Lists

ამოცანა: ორი დალაგებული ბმული სია გააერთიანეთ ერთ დალაგებულ სიად.

⚠️

Brute Force მიდგომა (რატომ არ ღირს): ორიგინალი მასალა აღწერს მიდგომას — ყველა ელემენტის მასივში/ვექტორში ჩაწერა, დალაგება, და ახალი ბმული სიის აგება. ეს მუშაობს, მაგრამ დაუსაბუთებლად ფლანგავს ინფორმაციას: ორივე შემავალი სია უკვე დალაგებულია — მთლიანი კომბინირებული მასივის ხელახლა დალაგება (O((n+m) log(n+m))) სრულიად ზედმეტია, როცა უბრალო შერწყმა (merge) საკმარისია O(n+m)-ში. ეს ლექცია 4-ის Merge Sort-ის merge() ეტაპის პირდაპირი გამოყენებაა.

რეკურსიული შერწყმა

def merge_sorted_lists(a: "Node", b: "Node") -> "Node":
    if a is None:
        return b
    elif b is None:
        return a

    if a.data <= b.data:
        result = a
        result.next = merge_sorted_lists(a.next, b)
    else:
        result = b
        result.next = merge_sorted_lists(a, b.next)
    return result

იტერაციული შერწყმა

def merge_sorted_lists_iter(a: "Node", b: "Node") -> "Node":
    if not a:
        return b
    if not b:
        return a

    if a.data <= b.data:
        head = tail = a
        a = a.next
    else:
        head = tail = b
        b = b.next

    while a and b:
        if a.data <= b.data:
            tail.next = a; tail = a; a = a.next
        else:
            tail.next = b; tail = b; b = b.next

    tail.next = a if a else b   # დარჩენილი „კუდის" პირდაპირ მიბმა
    return head
მიდგომადროითი სირთულესივრცითი სირთულე
Brute force (მასივში დალაგება)O((n+m) log(n+m))O(n+m)
რეკურსიული mergeO(n+m)O(n+m) — call stack
იტერაციული mergeO(n+m)O(1)
05 — ამოცანა 4

Reverse Linked List

ამოცანა: შეაბრუნეთ ბმული სიის მიმართულება — ისე, რომ ბოლო კვანძი გახდეს ახალი head.

იტერაციული ამონახსნი — სამი მაჩვენებელი

def reverse_list(head: "Node") -> "Node":
    prev = None
    curr = head
    while curr is not None:
        next_node = curr.next   # 1. შევინახოთ შემდეგი, სანამ არ დავკარგავთ მასზე წვდომას
        curr.next = prev        # 2. მიმართულების შებრუნება
        prev = curr              # 3. მაჩვენებლების წინ წაწევა
        curr = next_node
    return prev   # prev არის ახალი head

რეკურსიული ამონახსნი

def reverse_list_recursive(head: "Node") -> "Node":
    if head is None or head.next is None:
        return head              # საბაზისო შემთხვევა — 0 ან 1 კვანძი

    rest = reverse_list_recursive(head.next)   # დანარჩენის შებრუნება
    head.next.next = head        # თავდაპირველი მეორე კვანძი ახლა თავზე მიუთითებს
    head.next = None             # თავი ხდება ახალი კუდი
    return rest                   # ახალი head, ცვლილების გარეშე მთელი რეკურსიის განმავლობაში
მიდგომადროითი სირთულესივრცითი სირთულე
იტერაციულიO(n)O(1)
რეკურსიულიO(n)O(n) — call stack
06 — სცადეთ თავად

Reverse Linked List — ნაბიჯ-ნაბიჯ

დააჭირეთ „შემდეგი ნაბიჯს" და თვალი ადევნეთ, როგორ „ბრუნდება" ისარი უკან, ერთ კვანძზე ერთი ნაბიჯი — ზუსტად ისე, როგორც ზემოთ მოცემული იტერაციული კოდი მუშაობს.

მწვანე — უკვე შებრუნებული ნაწილი (prev-მხარე). ოქროსფერი — მიმდინარე curr. ცარიელი ხარვეზი curr-ის წინ გვიჩვენებს, რომ ის ბმული ჯერ არ არსებობს — curr ჯერ არ დამუშავებულა.

08 — რეალურ სამყაროში

სად მუშაობს ეს რეალურად

🔁

ციკლის აღმოჩენა — memory leaks

Floyd-ის ალგორითმის კონცეფცია (ორი მაჩვენებელი, სხვადასხვა სიჩქარით) გამოიყენება garbage collector-ებში ციკლური მითითებების საპოვნელად, რაც მეხსიერების გაჟონვის ხშირი მიზეზია.

🗄️

დუბლიკატების მოცილება — მონაცემთა გაწმენდა

დალაგებული ჩანაწერებიდან დუბლიკატების ერთი გავლით მოცილება ხშირად გამოიყენება ETL (Extract-Transform-Load) პროცესებში, სანამ დიდი მონაცემთა ბაზები დაიტვირთება.

🔀

Merge — გავრცელებული სისტემის ნიმუში

ორი დალაგებული ნაკადის (streams) შერწყმა ერთ დალაგებულ შედეგად — ზუსტად ეს ხდება, როცა რამდენიმე სერვერიდან უკვე დალაგებული შედეგები უნდა გაერთიანდეს (distributed sorting, log aggregation).

↩️

Reverse — Undo ფუნქციონალი

მოქმედებების ისტორიის (undo stack) შებრუნება, ან ბრაუზერის navigation stack-ის უკუღმა დამუშავება კონცეპტუალურად იმავე „სამი მაჩვენებლის" პატერნს იყენებს.

09 — პრაქტიკა

სავარჯიშოები — დღევანდელი ტექნიკების კომბინაცია

სამივე ქვემოთ მოცემული ამოცანა დღეს ნასწავლი ტექნიკების ბუნებრივი გაფართოებაა.

Palindrome Linked List მარტივი

დაადგინეთ, არის თუ არა ბმული სია პალინდრომი (LeetCode 234) — O(n) დროში, O(1) დამატებით სივრცეში.

def is_palindrome(head: "Node") -> bool:
    # 1. ვიპოვოთ შუა წერტილი (slow/fast — ლექცია 7-დან)
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next

    # 2. შევაბრუნოთ მეორე ნახევარი (დღევანდელი Reverse ტექნიკა)
    prev = None
    while slow:
        nxt = slow.next
        slow.next = prev
        prev = slow
        slow = nxt

    # 3. შევადაროთ პირველი ნახევარი შებრუნებულ მეორეს
    left, right = head, prev
    while right:
        if left.data != right.data:
            return False
        left = left.next
        right = right.next
    return True

ეს ამოცანა პირდაპირ აერთიანებს ლექცია 7-ის fast/slow ტექნიკას დღევანდელ Reverse-თან — კარგი დემონსტრაცია იმისა, თუ როგორ შენდება რთული ამონახსნი უკვე ნასწავლი მარტივი ბლოკებისგან.

Linked List Cycle II საშუალო

წინა ამოცანისგან განსხვავებით, არა მხოლოდ დაადგინეთ არის თუ არა ციკლი — იპოვეთ ის კვანძი, საიდანაც ციკლი იწყება (LeetCode 142).

def detect_cycle_start(head: "Node"):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            # ციკლი ნაპოვნია — ვიპოვოთ მისი დასაწყისი
            pointer = head
            while pointer is not slow:
                pointer = pointer.next
                slow = slow.next
            return pointer
    return None

მათემატიკური ჩვევა: როცა slow და fast პირველად შეხვდებიან, დამტკიცებადია, რომ head-იდან ციკლის დასაწყისამდე მანძილი ტოლია შეხვედრის წერტილიდან ციკლის დასაწყისამდე მანძილისა — ამიტომ ერთი მაჩვენებელი head-იდან და მეორე შეხვედრის წერტილიდან, ორივე ერთი ნაბიჯით, ზუსტად ციკლის დასაწყისში შეხვდება.

Reorder List რთული

მოცემულია სია L0 → L1 → … → Ln. გადაალაგეთ ის L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → … სახით — ახალი კვანძების შექმნის ან მასივში კოპირების გარეშე (LeetCode 143).

def reorder_list(head: "Node") -> None:
    if not head or not head.next:
        return

    # 1. შუა წერტილის პოვნა (fast/slow)
    slow, fast = head, head
    while fast.next and fast.next.next:
        slow = slow.next
        fast = fast.next.next

    # 2. მეორე ნახევრის შებრუნება
    second = slow.next
    slow.next = None
    prev = None
    while second:
        nxt = second.next
        second.next = prev
        prev = second
        second = nxt

    # 3. ორი ნახევრის გადაწნეხვა (interleave)
    first, second = head, prev
    while second:
        tmp1, tmp2 = first.next, second.next
        first.next = second
        second.next = tmp1
        first, second = tmp1, tmp2

ეს ამოცანა აერთიანებს სამივე დღეს ნასწავლ ტექნიკას ერთბაშად: fast/slow შუის საპოვნელად, Reverse — მეორე ნახევრისთვის, და ბოლოს ორი სიის „ჩავარცხნა" (merge-ის მსგავსი, მაგრამ მონაცვლეობითი პრინციპით). კარგი მტკიცებულებაა იმისა, რომ რთული ამოცანები ხშირად უბრალოდ რამდენიმე ცნობილი ტექნიკის კომბინაციაა.
